# Fabric Utility Mod

A basic Fabric mod for Minecraft 1.20.1.

## Setup

1. Ensure you have Java 17 installed.
2. Run `./gradlew build` to build the mod.
3. The built mod jar will be in `build/libs/`.

## Running

To run the mod in a development environment:

1. Run `./gradlew runClient` to launch Minecraft with the mod.
